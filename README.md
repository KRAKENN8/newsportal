# CyberPulse — News Portal

CyberPulse is a student news portal about technology: artificial intelligence, hardware, cybersecurity, gaming, and space. It has a public site for reading articles and commenting, and a separate admin panel for managing news.

The project follows a simple **MVC** layout on PHP, with MySQL as storage and custom CSS for the UI.

## Description

The application is a classic PHP news site:

- visitors browse the homepage, categories, full articles, and search results;
- registered users log in, update a profile username, and leave comments;
- editors use `/admin/` to add, edit, and delete articles.

Pretty URLs are handled with Apache `mod_rewrite` (`.htaccess`). Article images are stored in MySQL as `MEDIUMBLOB` (SVG generated by the seeder, or files uploaded in admin).

## Tech stack

| Layer | Technology |
|---|---|
| Language | PHP 8.0+ |
| Architecture | MVC (custom, no framework) |
| Database | MySQL / MariaDB |
| Access | PDO (`utf8mb4`) |
| Web server | Apache (XAMPP) |
| Routing | `.htaccess` + PHP routers |
| Auth | PHP sessions, `password_hash` / `password_verify` |
| Frontend | HTML, CSS, Font Awesome, Google Fonts |
| Admin extras | Bootstrap, jQuery (legacy assets) |

There is no Composer, Node, or npm. PHP files are served directly by Apache.

## Main features

**Public site**

- Homepage with featured / latest stories
- Full news list (`all`)
- Filter by category (`category?id=`)
- Article page with image, text, and comments
- Keyword search (`search?otsi=`)
- About page
- Registration (username, email, password ≥ 6 characters)
- Login / logout
- Profile: view email, change username
- Comments: POST only when a session user exists

**Admin panel**

- Login form
- News list
- Create news (title, text, category, picture)
- Edit news
- Delete news (confirmation form)

**Demo data**

- SQL dump `cyberpulse.sql` with sample articles
- CLI seeder `seed.php` that truncates content tables and inserts English categories, articles, SVG covers, and comments

## Requirements

- Windows, macOS, or Linux
- [XAMPP](https://www.apachefriends.org/) (Apache + PHP + MySQL/MariaDB), or an equivalent stack
- PHP 8.0 or newer
- PHP extensions: `pdo_mysql`, `mbstring`, `session`
- Apache modules: `mod_rewrite`
- `AllowOverride All` for the site directory (so `.htaccess` works)

Expected local path with XAMPP on Windows:

```text
C:\xampp\htdocs\newsportal
```

## Installation

### 1. Place the project

Copy or clone the repository into the web root:

```text
C:\xampp\htdocs\newsportal
```

Folder name `newsportal` matches the default URLs below.

### 2. Start services

In **XAMPP Control Panel** start:

1. Apache
2. MySQL

### 3. Create the database

The app connects to a database named **`cyberpulse`**.

Open http://localhost/phpmyadmin and create a database:

- Name: `cyberpulse`
- Collation: `utf8mb4_unicode_ci`

Default credentials in `inc/Database.php`:

| Setting | Value |
|---|---|
| Host | `localhost` |
| User | `root` |
| Password | *(empty)* |
| Database | `cyberpulse` |

If your MySQL user or password is different, edit `inc/Database.php` before running the site.

### 4. Load schema and data

Pick **one** of the following.

**Option A — import the dump (recommended first run)**

1. Select database `cyberpulse` in phpMyAdmin.
2. Open **Import**.
3. Choose `cyberpulse.sql`.
4. Run the import.

The dump file header may mention `newsportal`. That is only an export comment. Import the tables **into** `cyberpulse`.

**Option B — seed after tables already exist**

From the project root:

```bash
php seed.php
```

The seeder:

- converts tables to `utf8mb4`;
- truncates `comments`, `news`, and `category`;
- creates or updates demo users;
- inserts 5 categories, 6 articles with SVG images, and sample comments.

Do not run the seeder if you want to keep existing articles.

## How to run

1. Apache and MySQL are running.
2. Database `cyberpulse` exists and has tables.
3. Open the public site:

   http://localhost/newsportal/

4. Open the admin panel:

   http://localhost/newsportal/admin/

The front controller is `index.php` (public) and `admin/index.php` (admin). Rewrite rules send unknown paths to those files.

## What each layer does

| Path | Responsibility |
|---|---|
| `index.php` | Starts the session, loads models, includes the public router, prints `$response` |
| `inc/Database.php` | Opens a PDO connection; `getOne`, `getAll`, `executeRun` |
| `route/routing.php` | Reads the last URL segment and GET/POST data, calls `Controller` |
| `controller/Controller.php` | Loads data from models and includes the matching view |
| `model/` | SQL and business rules (no HTML) |
| `view/` | Markup; most pages fill `$content` and include `layout.php` |
| `admin/index.php` | Same idea for the back office |
| `admin/modelAdmin/modelAdmin.php` | Admin session login / logout |
| `admin/modelAdmin/modelAdminNews.php` | Create / update / delete news |
| `admin/controllerAdmin/` | Admin page flow |
| `admin/viewAdmin/` | Admin forms and lists |
| `seed.php` | One-shot English demo dataset |

Request flow (public):

```text
Browser → Apache (.htaccess) → index.php → routing.php → Controller → Model → View → HTML
```

## Database

Tables:

| Table | Purpose |
|---|---|
| `users` | Accounts: username, email, hashed password, status (`admin` / `user`), registration date |
| `category` | Rubrics (AI, Hardware, Cybersecurity, Gaming, Space) |
| `news` | Title, text, picture BLOB, `category_id`, `user_id` |
| `comments` | `user_id`, `news_id`, text, datetime |

`news` has foreign keys to `category` and `users`.

## Public routes

Defined in `route/routing.php`.

| Path | Action |
|---|---|
| `/` | Homepage |
| `all` | All news |
| `category?id=` | News in a category |
| `news?id=` | Single article |
| `search?otsi=` | Search |
| `about` | About |
| `registerForm` | Registration form |
| `registerAnswer` | Registration POST handler |
| `formLogin` | Login form |
| `loginAnswer` | Login POST handler |
| `profile` | Profile (session required) |
| `logout` | Destroy session |
| `insertcomment` | Add comment (POST, session required) |

Unknown paths render a 404 view.

## Admin routes

Defined in `admin/routeAdmin/routingAdmin.php`. Base URL: `/newsportal/admin/`.

| Path | Action |
|---|---|

| `login` | Process login |
| `logout` | Log out |
| `newsAdmin` | News list |
| `newsAdd` | Add form |
| `newsAddResult` | Save new article |
| `newsEdit?id=` | Edit form |
| `newsEditResult?id=` | Save changes |
| `newsDel?id=` | Delete confirmation |
| `newsDelResult?id=` | Delete article |

## Configuration

All DB settings live in `inc/Database.php` (`$host`, `$user`, `$password`, `$baseName`). Both public and admin code use this class.

The router uses the **last** path segment. Keep the project in `htdocs/newsportal`, or point a virtual host at the repository root.
